Web Image Bridge (Gemini / ChatGPT)

Kết nối trực tiếp SillyTavern với tab Gemini Web hoặc ChatGPT Web để vẽ ảnh chất lượng cao mà không tốn chi phí API.

Tự động ghép vào CUỐI câu lệnh vẽ ảnh (/draw và Agent tool). Để trống nếu không dùng.
Trạng thái kết nối Tab thời gian thực:
Userscript Bridge: Đang kiểm tra...
Gemini Web (gemini.google.com): 🔴 Chưa mở tab
ChatGPT Web (chatgpt.com): 🔴 Chưa mở tab
Hướng dẫn kích hoạt & sử dụng:

1. Cài đặt tiện ích Tampermonkey trên trình duyệt của bạn.
2. Cài đặt script Kaiz Web Image Bridge.
3. Mở sẵn 1 tab gemini.google.com hoặc chatgpt.com (đã đăng nhập).
4. Trong khung chat SillyTavern, gõ /draw <mô tả> hoặc để Agent tự động vẽ ảnh!
